# SEO Services Funnel Page

A single-page funnel: hero → problem → process/timeline → results → packages →
niche breakdown → guarantee → FAQ → CTA.

## Before you publish — replace these placeholders

- `[Your Name]` — appears in nav, hero, footer, CTA email
- `youremail@example.com` — final CTA + footer mailto links
- `"[your main keyword]"` in the hero rank widget
- `[Client / case study]` labels in the Results section — swap in real numbers once you have them
- Confirm the $500 / $1,000 / $1,500 pricing and backlink counts match what you actually want to commit to

## Run it locally

Just open `index.html` in a browser — no build step, no dependencies.

## Deploy free with GitHub Pages

1. Create a new GitHub repo (e.g. `seo-services`).
2. Push these three files (`index.html`, `styles.css`, `script.js`) to the `main` branch.
   ```bash
   git init
   git add .
   git commit -m "Launch SEO funnel page"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/seo-services.git
   git push -u origin main
   ```
3. On GitHub: **Settings → Pages → Source → Deploy from a branch → main / (root)**.
4. Your site goes live at `https://YOUR_USERNAME.github.io/seo-services/` within a couple minutes.

### Optional free custom-ish domain
GitHub Pages subdomains are free forever. If you later want `yourname.com` instead
of the github.io URL, that's the only paid piece (domain registration, ~$10-15/yr) —
everything else here stays free.
